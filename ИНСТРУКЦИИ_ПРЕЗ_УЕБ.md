# Инсталиране на Vega-S Local Thermostat през HACS (без терминал)

## Подготовка в GitHub

1. Създай ново **public** GitHub хранилище с име `vega-s-local`.
2. Разархивирай този ZIP на компютъра.
3. В новото GitHub хранилище натисни **Add file → Upload files**.
4. Качи **съдържанието** на папката, а не самия ZIP. Трябва да има структура:

```
vega-s-local/
  hacs.json
  README.md
  custom_components/
    vega_s_local/
      manifest.json
      __init__.py
      api.py
      climate.py
      config_flow.py
      coordinator.py
      const.py
      translations/
        bg.json
        en.json
```

5. В `custom_components/vega_s_local/manifest.json` промени двете полета `documentation` и `issue_tracker` така, че вместо `YOUR_GITHUB_USERNAME` да съдържат твоето GitHub потребителско име. Направи това през бутона Edit в GitHub.

## Добавяне чрез HACS

1. Home Assistant → HACS → меню `...` → **Custom repositories**.
2. Въведи адрес `https://github.com/ТВОЯ-ПОТРЕБИТЕЛ/vega-s-local`.
3. Избери тип **Integration**, после **Add**.
4. Отвори новото хранилище във HACS и натисни **Download**.
5. Рестартирай Home Assistant (само HA, не Docker хоста).
6. **Settings → Devices & services → Add integration** → **Vega-S Local Thermostat**.
7. Въведи LAN IP адреса на ESP8266 (само IP, без http://).
8. Добави получената `climate` единица в стандартна **Thermostat card**.

Важно: ESP8266 трябва да е с фърмуер **v6.2 HA Local**. Само v6.1 не е достатъчна — липсват `/api/ha/*` командите.

## Проверка преди добавяне

В браузър от локалната мрежа отвори:

- `http://IP-НА-ESP/health` — очаквано: `Heater Performance v6.2 HA Local alive`
- `http://IP-НА-ESP/api/ha/state` — очаква се JSON с temperature, target, enabled, relay и sensor_ok.

При проблем с HACS провери дали GitHub е публичен и файловете са под `custom_components/vega_s_local/`, а не `home_assistant/custom_components/...`.
